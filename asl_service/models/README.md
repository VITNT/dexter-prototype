# OpenHands WLASL2000 ST-GCN checkpoint

The ASL-word service uses the released AI4Bharat/OpenHands checkpoint at:

`asl_service/models/openhands_wlasl2000_stgcn.ckpt`

The checkpoint came from the OpenHands `wlasl_stgcn.zip` release bundle and is
stored with Git LFS. Its verified artifact contract is:

- file size: `43,362,699` bytes
- SHA-256: `7a86185715e1a63a16dd87fbf6433e86bf1be4627193c181b148398a8603bc7a`
- PyTorch Lightning: `1.4.8`
- training epoch: `213`
- output classes: `2,000`
- model input: `[batch, 2, frames, 27]`

The accompanying `openhands_wlasl2000_stgcn.yaml` is the original training
configuration. `wlasl2000_labels.txt` is generated by sorting the 2,000 glosses
in the official WLASL v0.3 metadata, matching `WLASLDataset.read_glosses()` in
OpenHands.

Run `git lfs pull` after cloning. A valid working-tree checkpoint should be
about 41 MiB, not a small text pointer. The service loads the Lightning archive
with PyTorch's restricted `weights_only=True` loader and strict key/shape
validation; it does not require PyTorch Lightning at runtime.
